Why this layout works for agents

  • Context is scoped by franchise.
  • Manifest metadata makes script-to-config dependencies explicit.
  • MCP can expose narrow resources instead of the entire repository.
  • Templates keep future franchises consistent.

Suggested MCP resources

  • get_repo_context()
  • get_franchise_context(franchise)
  • get_franchise_manifest(franchise)
  • get_script_dependencies(franchise, script)
  • search_context(query, franchise?)

Example Agent Query

For Venclexta, explain the purpose of <script>, identify all configuration files it consumes, and summarize the business rules that can change its output.

The agent should resolve the request through franchise context → manifest → script → configuration, without loading unrelated franchises.
